# Newton Cloud: terminate task

Original name: 牛顿云-终止任务  
API: `com.alibaba.agent:newtoncloud.task.kill:1` · Category: Inquiries (Newton Cloud)  
Doc page: https://open.1688.com/api/apidocdetail.htm?id=com.alibaba.agent:newtoncloud.task.kill-1  
Request URL: `https://gw.open.1688.com/openapi/param2/1/com.alibaba.agent/newtoncloud.task.kill/{appKey}`  
Requires user authorization (access_token) · Requires signature

Terminate the task with the given taskId, mark it with the KILL status, and return killed.
